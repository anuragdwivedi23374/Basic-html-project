# 🎮 TikTok Swipe Game

A fun and interactive **TikTok-style swipe game** built using **HTML, CSS, and JavaScript**.  
Swipe left/right (or use arrow keys) to catch ❤️ and avoid 💣 within the time limit.

## 🕹️ How to Play

- Tap **Start Game**
- Swipe **Left / Right** on mobile to move the player
- Use **← → arrow keys** on desktop
- Catch ❤️ to increase score
- Avoid 💣 (bomb) or lose points
- Game ends after **30 seconds**

---

## ✨ Features

- TikTok-inspired vertical game UI
- Mobile swipe + keyboard controls
- Falling items animation
- Score & countdown timer
- Simple, clean & responsive design
- Pure Vanilla JavaScript (no libraries)
